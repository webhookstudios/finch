# Finch 1.0.1

- Mark All as Played, in a show's More menu, with Undo.
- Discover: hover a show to get a + button that subscribes in one click.
- The popular list loads reliably again, and Discover has Try Again if the directory can't be reached.
- The volume percentage beside the slider no longer misses some changes.

# Finch 1.0.0

First release.

- Podcasts: discover and search, subscribe, New Episodes, Up Next, downloads, show notes, OPML import and export.
- Listening: resume, adjustable skip, 0.5x to 3x speed, sleep timer.
- Radio: browse stations by country and genre, search, favorites, recently played, and custom stream addresses.
- Twelve color themes, ten accent colors, and light or dark, right in the main menu.
- The volume shows as a percentage while you change it.
- Media keys and the system's media controls.
